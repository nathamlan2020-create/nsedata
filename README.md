# NSE data

Nifty 500 price data archive.

- `daily/nse500_daily_2005-2026.zip`: daily OHLCV, 2005 to Oct 2026, one CSV per stock plus the Nifty 500 index (`IDX_CRSLDX.csv`). Source: Yahoo Finance.
- `intraday/5min/`: 5-minute bars, last 60 days.
- `intraday/1min/YYYY/MM/`: 1-minute bars and chart image for each trading day.

Note: only stocks in today's Nifty 500 (survivorship bias).
